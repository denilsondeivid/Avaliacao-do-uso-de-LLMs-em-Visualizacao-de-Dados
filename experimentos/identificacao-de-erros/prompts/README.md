# Prompts da etapa de identificacao

Esta pasta foi mantida para concentrar a documentacao de prompting da etapa de identificacao de erros.

Pelas evidencias dos materiais, a analise considera pelo menos as seguintes tecnicas:

- Zero-shot
- Few-shot
- Thought-Chain

As rodadas e respostas brutas dos modelos estao disponiveis em `../dados/brutos/respostas-llms/`.
