# Prompts da etapa de correcao

Esta pasta foi mantida para concentrar a documentacao de prompting da etapa de correcao de erros.

Com base nos materiais atuais, esta etapa envolve a analise do erro de visualizacao e a proposicao de uma versao corrigida do grafico sem introduzir novos problemas visuais.

As respostas brutas dos modelos estao disponiveis em `../dados/brutos/respostas-llms/`.
